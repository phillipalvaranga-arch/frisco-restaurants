# Frisco Restaurant Finder
Installable web app (PWA). Search Frisco, TX restaurants by food type, dish or name; ranked by weighted Google rating + review count.

- Data as of Nov 24, 2026: Google Maps public listings (rating, reviews, address, phone, hours, website) + each restaurant's own online menu (dish names, listed prices).
- No orders, no logins, no keys. Favorites are stored only in this browser (localStorage).
- `tools/` holds the data-building scripts used to make `data.js`.
